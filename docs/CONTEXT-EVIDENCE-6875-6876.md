Sichtbar:

- mehrere senkrechte Pfosten unter diesem Balken,

- zentrale kleine Aufbau-/Bedienstruktur,

Nutzbar für:

- Vorbereitung weiterer Wasserseitenaufnahmen.

## Konsequenz für das Arbeitsmodell

Das Rekonstruktionsobjekt wird ab jetzt ausdrücklich als Gesamtsystem behandelt:

**Radkörper + Welle/Lagerung + Radstatt + Lagerstöcke + obere/untere/seitliche Rahmen + Trog/Rinne + Wasserraum + Uferbezug.**

Stationäre Kontextgeometrie, die aus diesen Bildern nur plausibel, aber nicht metrisch bestimmt werden kann, erhält den Status:

- `context-observed` wenn das Bauteil sichtbar ist,
- `context-hypothesis` wenn Lage/Form nur angenähert wird,
- `context-unknown` wenn Funktion oder Topologie offen bleibt.

Keine dieser Kontextannahmen wird ohne Vor-Ort-Messung zu Ist-Geometrie hochgestuft.
